Фото и файлы кладутся в папку самой статьи, рядом с её текстовыми файлами. Все языковые версии используют одни и те же файлы, поэтому каждое фото загружается только один раз.

<!--more-->

## Куда класть файлы {#files-folder}

```text
content/posts/guide-media/
├── index.uz.md
├── index.uz-cyrl.md
├── index.ru.md
├── index.en.md
├── cover.jpg
├── workspace.jpg
├── landscape.jpg
├── typewriter.jpg
├── buildings.jpg
└── sample-document.pdf
```

- Давайте файлам простые имена: строчные латинские буквы и дефисы, без пробелов. Пишите `team-meeting.jpg`, а не `IMG 2034 (1).JPG`.
- Для фотографий используйте JPG, для скриншотов — PNG.
- Большие фото прямо с телефона подходят: сайт сам уменьшит их до удобного для интернета размера.

## Обложка {#cover}

Обложка задаётся в заголовке файла, а не в тексте. Она показывается в начале статьи и на её карточке в списке статей:

```yaml
cover:
  image: "cover.jpg"
  alt: "Небоскрёбы города на закате"     # описание фото для программ чтения с экрана
  caption: "Фото: Kevin Young / Unsplash" # подпись под фото на странице статьи
```

Чтобы показывать обложку только на странице статьи, а не в списке, добавьте `hiddenInList: true` под `cover:`.

## Фото в тексте {#photo}

```markdown
![Ноутбук и блокнот на деревянном столе](workspace.jpg)
```

![Ноутбук и блокнот на деревянном столе](workspace.jpg)

Текст в квадратных скобках описывает фото. Читатели его не видят, но его используют программы чтения с экрана и поисковики, и он появляется, если фото не загрузилось.

## Фото с подписью {#caption}

```markdown
{{</* figure src="landscape.jpg" alt="Синий фьорд между скалистыми горами"
    title="Фото с подписью"
    caption="Фото: [Alexey Topolyanskiy](https://unsplash.com/photos/-oWyJoSqBRM) / Unsplash" */>}}
```

{{< figure src="landscape.jpg" alt="Синий фьорд между скалистыми горами"
    title="Фото с подписью"
    caption="Фото: [Alexey Topolyanskiy](https://unsplash.com/photos/-oWyJoSqBRM) / Unsplash" >}}

`title` показывается жирным, `caption` — под ним. Оба необязательны, и внутри `caption` работают ссылки.

## Фото меньше и по центру {#size}

```markdown
{{</* figure src="typewriter.jpg" alt="Старая пишущая машинка" width="360" align="center"
    caption="Ширина 360 пикселей, по центру" */>}}
```

{{< figure src="typewriter.jpg" alt="Старая пишущая машинка" width="360" align="center"
    caption="Ширина 360 пикселей, по центру" >}}

Без `width` фото занимает всю ширину текста.

## Фото, которое открывается в полном размере {#full-size}

```markdown
{{</* figure src="buildings.jpg" alt="Офисные башни, вид снизу"
    link="buildings.jpg" target="_blank"
    caption="Нажмите на фото, чтобы открыть его в полном размере в новой вкладке" */>}}
```

{{< figure src="buildings.jpg" alt="Офисные башни, вид снизу"
    link="buildings.jpg" target="_blank"
    caption="Нажмите на фото, чтобы открыть его в полном размере в новой вкладке" >}}

В `link` можно указать и любой адрес, например связанную статью.

## Фото с другого сайта {#external-photo}

```markdown
![Описание](https://example.com/photo.jpg)
```

Так можно, но фото пропадёт, если другой сайт его удалит или переместит. По возможности сохраняйте фото в папку статьи.

## Видео с YouTube {#youtube}

Видео не загружаются на сайт. Они воспроизводятся с YouTube, поэтому нужен только ID видео — код в конце его адреса:

| Адрес на YouTube                                | ID видео      |
|:------------------------------------------------|:--------------|
| `https://www.youtube.com/watch?v=aqz-KE-bpKQ`   | `aqz-KE-bpKQ` |
| `https://youtu.be/aqz-KE-bpKQ`                  | `aqz-KE-bpKQ` |
| `https://www.youtube.com/shorts/aqz-KE-bpKQ`    | `aqz-KE-bpKQ` |

Затем напишите:

```markdown
{{</* youtube aqz-KE-bpKQ */>}}
```

{{< youtube aqz-KE-bpKQ >}}

Видео занимает всю ширину текста и сохраняет пропорции на телефонах.

Чтобы видео началось с определённой секунды, например с 1:00, используйте `start`. `end` останавливает его на заданной секунде:

```markdown
{{</* youtube id="aqz-KE-bpKQ" start="60" end="90" */>}}
```

{{< youtube id="aqz-KE-bpKQ" start="60" end="90" >}}

*Видео: «Big Buck Bunny» © Blender Foundation, CC BY 3.0. Строку курсивом, как эта, можно писать под видео вместо подписи.*

## Файлы для скачивания {#download}

Положите файл в папку статьи и поставьте на него ссылку:

```markdown
[Скачать пример документа (PDF, 24 КБ)](sample-document.pdf)
```

[Скачать пример документа (PDF, 24 КБ)](sample-document.pdf)

Так можно прикрепить файл любого типа: `.pdf`, `.docx`, `.xlsx`, `.zip` и другие. Указывайте в тексте ссылки тип и размер файла, чтобы читатель знал, что он скачивает.
