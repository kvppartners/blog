Расм ва файллар мақоланинг ўз папкасига, унинг матн файллари ёнига қўйилади. Барча тил версиялари бир хил файллардан фойдаланади, шунинг учун ҳар бир расм фақат бир марта юкланади.

- Фотосуратлар учун JPG, скриншотлар учун PNG ишлатинг.
- Телефондан олинган катта расмлар ҳам бўлаверади: сайт уларни интернет учун қулай ўлчамга ўзи кичрайтиради.

## Муқова расми {#cover}

Муқова матнда эмас, файл сарлавҳасида белгиланади. У мақола бошида ва мақолалар рўйхатидаги карточкасида кўринади:

```yaml
cover:
  image: "cover.jpg"
  alt: "Қуёш ботаётган пайтдаги шаҳар"   # экран ўқувчи дастурлар учун расм тавсифи
  caption: "Расм: Kevin Young / Unsplash"  # мақола саҳифасида расм остидаги изоҳ
```

Муқовани рўйхатда эмас, фақат мақола саҳифасида кўрсатиш учун `cover:` остига `hiddenInList: true` қўшинг.

## YouTube видеоси {#youtube}

Видеолар сайтга юкланмайди. Улар YouTube’дан ижро этилади, шунинг учун фақат видео ID’си — манзил охиридаги код керак:

| YouTube манзили                                 | Видео ID      |
|:------------------------------------------------|:--------------|
| `https://www.youtube.com/watch?v=aqz-KE-bpKQ`   | `aqz-KE-bpKQ` |
| `https://youtu.be/aqz-KE-bpKQ`                  | `aqz-KE-bpKQ` |
| `https://www.youtube.com/shorts/aqz-KE-bpKQ`    | `aqz-KE-bpKQ` |

Кейин шундай ёзинг:

```markdown
{{</* youtube aqz-KE-bpKQ */>}}
```

{{< youtube aqz-KE-bpKQ >}}

Видео матннинг бутун энини эгаллайди ва телефонларда ҳам шаклини сақлайди.

Видеони маълум бир сониядан, масалан 1:00 дан бошлаш учун `start` дан фойдаланинг. `end` уни белгиланган сонияда тўхтатади:

```markdown
{{</* youtube id="aqz-KE-bpKQ" start="60" end="90" */>}}
```


Шу тарзда исталган турдаги файлни бириктириш мумкин: `.pdf`, `.docx`, `.xlsx`, `.zip` ва бошқалар. Ўқувчи нимани юклаб олаётганини билиши учун ҳавола матнида файл тури ва ҳажмини кўрсатинг.
