Мақолалар **Markdown** форматидаги оддий матн файлларидир: бир нечта оддий белгиларни ёзасиз ва улар форматланган матнга айланади. Қуйидаги ҳар бир бўлимда аввал нима ёзиш кераклиги, кейин эса сайтда қандай кўриниши кўрсатилган.

<!--more-->

## Мақолалар қаерда сақланади {#where}

Ҳар бир мақола `content/posts/` ичидаги папкадир. Унда ҳар бир тил учун биттадан матн файли, шунингдек мақоланинг расм ва файллари туради:

```text
content/posts/my-article/
├── index.uz.md        ← ўзбекча (лотин)
├── index.uz-cyrl.md   ← ўзбекча (кирилл)
├── index.ru.md        ← русча
├── index.en.md        ← инглизча
└── photo.jpg          ← барча тиллар учун умумий
```

Папка номи саҳифа манзилига айланади, масалан `/uz-cyrl/posts/my-article/`. Фақат кичик лотин ҳарфлари ва чизиқчалардан фойдаланинг.

Янги мақола бошлаш учун мавжуд папкадан нусха олинг ёки қуйидагини бажаринг:

```bash
hugo new posts/my-article/index.uz-cyrl.md
```

## Файл сарлавҳаси {#header}

Ҳар бир файл иккита `---` қатори орасидаги блок билан бошланади. Унда мақоланинг матни эмас, созламалари сақланади:

```yaml
---
title: "D-2 талаба визасини қандай олиш мумкин"   # рўйхатда ва саҳифада
date: 2026-10-03T12:00:00+09:00   # нашр санаси; рўйхат шу бўйича сараланади
draft: true                       # true = яширин; фақат `hugo server -D` билан кўринади
categories: ["Қўлланмалар", "Визалар"]   # битта ёки бир нечта категория
description: "Мақолалар рўйхатида сарлавҳа остидаги битта жумла"
---
```

- Мақола нашрга тайёр бўлганда `draft: false` қилинг.
- Ҳар бир мақолада унинг сарлавҳаларидан тузилган мундарижа бор. Уни яшириш учун файл сарлавҳасига `ShowToc: false` қўшинг; `TocOpen: true` уни дарҳол очиқ ҳолда кўрсатади.
- Мақолани Telegram каналга жойлагандан кейин `telegram: "https://t.me/kvp_partners/123"` (пост ҳаволаси) қўшинг — мақола остида шу постнинг изоҳлари кўринади.
- Бир тилдаги барча мақолаларда ҳар бир категорияни бир хил ёзинг: «Виза» ва «Визалар» икки хил тугмага айланади.
- Мақола бошидаги расм (`cover`) [Расм, видео ва файлларни қўшиш](/posts/guide-media/) мақоласида тушунтирилган.

## Сарлавҳалар {#headings}

Мақола номи энг катта сарлавҳа, шунинг учун матн ичидаги сарлавҳалар иккита `#` билан бошланади:

```markdown
## Бўлим
### Кичик бўлим
#### Кичикроқ сарлавҳа
```

Бу саҳифада улар аллақачон ишлатилган: юқоридаги «Сарлавҳалар» — `##`, пастдаги «Қалин, курсив, ўчирилган» эса `###` сарлавҳа. Саҳифа бошидаги мундарижа ҳам сарлавҳалардан тузилади.

## Хатбошилар ва янги қатор {#paragraphs}

Хатбошилар орасида бўш қатор қолдиринг. Битта қатор кўчириш эътиборга олинмайди; хатбоши ичида янги қатор бошлаш учун қатор охирига тескари қия чизиқ `\` қўйинг.

```markdown
Биринчи хатбоши.

Иккинчи хатбоши,\
мажбурий янги қатор билан.
```

Биринчи хатбоши.

Иккинчи хатбоши,\
мажбурий янги қатор билан.

## Матн услублари {#text-styles}

### Қалин, курсив, ўчирилган

```markdown
**қалин**, *курсив*, ***қалин курсив***, ~~ўчирилган~~
```

**қалин**, *курсив*, ***қалин курсив***, ~~ўчирилган~~

### Ажратиш, тагига чизиш, пастки ва юқори индекс

```markdown
==ажратилган==, ++тагига чизилган++, H~2~O, 25 м^2^
```

==ажратилган==, ++тагига чизилган++, H~2~O, 25 м^2^

### Қатор ичидаги код

Аниқ қийматлар, файл номлари ёки буйруқлар учун:

```markdown
Анкетада виза тури `D-2` деб ёзилади.
```

Анкетада виза тури `D-2` деб ёзилади.

### Автоматик типографика

Тўғри қўштирноқлар, иккита чизиқча ва учта нуқта автоматик алмаштирилади:

```markdown
"Қўштирноқ" -- қисқа тире --- узун тире...
```

"Қўштирноқ" -- қисқа тире --- узун тире...

«Бурчакли» қўштирноқ ва бошқа ҳар қандай белгини тўғридан-тўғри ёзинг: «», №, ₩, €, ©, 🇰🇷 🎓 ✈️.

## Код блоклари {#code}

Коддан олдинги ва кейинги қаторларга учта тескари апостроф қўйинг. Биринчи апострофлардан кейин тил номини ёзсангиз, код рангли бўлади:

````markdown
```python
def days_left(stay, used):
    return stay - used
```
````

## Рўйхатдаги тавсиф {#preview}

Мақолалар рўйхатидаги ҳар бир карточкада сарлавҳа остида мақола тавсифи кўрсатилади: файл сарлавҳасидаги `description: "…"`. Мақола саҳифасининг ўзида у кўринмайди, шунинг учун уни ўқувчида мақолани очиш истаги уйғонадиган қилиб ёзинг. Тавсифи йўқ мақолада матннинг боши кўрсатилади: `<!--more-->` қаторидан олдинги матн (бу мақолада у биринчи хатбошидан кейин турибди), бу қатор бўлмаса эса тахминан дастлабки 70 та сўз.
